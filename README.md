Abstract
This paper examines sector‑wise behavior within the S&P 500 index, aiming to detect performance differences and predict future cumulative returns. Using an open‑source dataset of historical price and market‑capitalization data for S&P 500 constituents, daily weights are reconstructed and back‑propagated market caps to form a detailed sector‑level time series. An LSTM‑based neural‑network architecture forecasts each sector’s cumulative returns under various coverage thresholds, highlighting how missing data or index‑membership changes impact results. The findings infer that certain sectors deviate considerably from the broader index while others maintain a constant trend.
